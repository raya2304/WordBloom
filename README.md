# WordBloom — Vocabulary Builder

**Grow your words. Express your world.**

WordBloom is an interactive and responsive vocabulary learning website designed to help users improve their English vocabulary through word exploration, interactive quizzes, flashcards, and personalised word collections.

## Overview

WordBloom makes learning new words simple and engaging. Users can explore vocabulary, understand definitions, learn pronunciation guides, discover synonyms, practise with example sentences, and test their knowledge through interactive quizzes.

## Features

- **Featured Word:** Discover vocabulary with meanings, pronunciation guides, and example sentences.
- **Word Library:** Explore a collection of useful English words with definitions and synonyms.
- **Search and Filters:** Find words by name, meaning, category, and difficulty level.
- **Interactive Word Cards:** Review vocabulary and practise remembering definitions.
- **Saved Words:** Bookmark favourite words and access them in a personal dictionary.
- **Vocabulary Quiz:** Answer multiple-choice questions and receive instant feedback.
- **Progress Tracking:** Monitor explored words, saved vocabulary, quiz accuracy, and best scores.
- **Local Storage:** Preserve saved words and learning statistics in the browser.
- **Responsive Design:** Enjoy a clean interface on desktop, tablet, and mobile devices.

## Technologies Used

- HTML5
- Tailwind CSS
- JavaScript
- Browser Local Storage
- Google Fonts

## Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/YOUR-USERNAME/wordbloom-vocabulary-builder.git
```

### 2. Open the project

Navigate to the project folder:

```bash
cd wordbloom-vocabulary-builder
```

### 3. Run the website

Open `index.html` in your web browser.

No backend server or database setup is required. An internet connection is needed to load Tailwind CSS and Google Fonts from their external services.

## How to Use

1. Open the website and explore the featured vocabulary.
2. Navigate to **Learn Words** to browse the vocabulary library.
3. Search for specific words or filter them by category and difficulty.
4. Save your favourite words for later revision.
5. Use Quick Review to practise remembering word meanings.
6. Take the Daily Vocabulary Quiz to test your knowledge.
7. Track your learning progress on the home page.

## Limitations

WordBloom currently uses a predefined vocabulary collection and browser-based Local Storage. Learning progress is stored locally and does not synchronise between different browsers or devices.
